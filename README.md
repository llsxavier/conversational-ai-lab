# Conversational AI Lab

Projeto educacional para desenvolver autonomia em:

- JavaScript moderno;
- TypeScript;
- criação e depuração de APIs;
- testes automatizados;
- integrações;
- chatbots e agentes conversacionais.

## Requisitos

- Node.js 22 ou superior;
- npm;
- VS Code;
- Git.

## Instalação

```bash
npm install
```

## Executar

```bash
npm run dev
```

A API ficará disponível em:

```text
http://localhost:3000
```

## Testes

```bash
npm test
```

## Verificação de tipos

```bash
npm run typecheck
```

## Fluxo de trabalho

1. Leia a tarefa em `tasks/current-sprint.md`.
2. Abra o arquivo da história correspondente.
3. Crie uma branch.
4. Implemente sem pedir a solução completa ao agente.
5. Execute testes e verificação de tipos.
6. Peça revisão sem alteração automática.
7. Corrija os problemas encontrados.
8. Registre a retrospectiva na tarefa.
